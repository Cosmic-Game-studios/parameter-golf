# Session Loop

1. Sync `STATE.json`, baseline, scoreboard, evidence, decisions, negatives, and handoff.
2. Choose one bounded cycle from the portfolio:
   - conservative
   - orthogonal
   - high-upside
   - reproduction
3. Establish the exact baseline and comparison frame.
4. Run one narrow experiment.
5. Decide `keep`, `revert`, `crash`, or `park`.
6. Update evidence, priorities, open questions, and next session.
7. Stop only after the next action is low-entropy.
